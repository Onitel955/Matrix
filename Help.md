# Довідка

## Запуск

1. Переконайтеся, що у вас встановлено Python 3 — сторонні бібліотеки не потрібні.

2. Відкрийте термінал (або командний рядок) у папці з файлом `Martix_ver2.py`.

3. Виконайте команду:

   ```bash
   python3 Martix_ver2.py
   ```

   (або `python Martix_ver2.py` — залежно від налаштувань вашої операційної системи).

   Ім'я файлу пишеться з великої літери **M**: на Linux регістр має значення, і `python3 matrix.py` там не запуститься.

4. Щоб зупинити ефект і повернутися до звичайного терміналу, натисніть **Ctrl + C**.

   Анімація виконується в альтернативному буфері екрана, тому після виходу ваша історія команд лишається на місці — прибирати за скриптом не потрібно.

## Розтягніть вікно перед запуском

Дощ малюється на все вікно терміналу, тому чим воно більше, тим ефектніше виглядає. Повноекранний режим (`Cmd + Ctrl + F` на macOS, `F11` на Windows і Linux) дає найкращу картинку.

Розмір вікна можна змінювати і під час роботи — скрипт підхопить його на льоту.

## Як змінити швидкість, густоту й вигляд

Налаштування зібрані на початку `Martix_ver2.py`, у блоці `--- НАЛАШТУВАННЯ ЕФЕКТУ ---`. Відкрийте файл у будь-якому редакторі й змініть потрібне значення.

Типово дощ опускається неспішно, приблизно 3 рядки на секунду.

| Хочу... | Що змінити |
|---|---|
| ще повільніший дощ | зменшити `DROP_SPEED`, напр. на `(0.03, 0.1)` |
| швидший дощ | збільшити `DROP_SPEED`, напр. на `(0.2, 0.6)` |
| справжню "зливу", як у фільмі | `DROP_SPEED = (0.4, 1.1)` і `SPAWN_CHANCE = 0.01` |
| плавнішу картинку | збільшити `FPS` до `60` |
| щільніший потік | збільшити `SPAWN_CHANCE` до `0.004` |
| рідший потік | зменшити `SPAWN_CHANCE` до `0.001` |
| довші хвости | збільшити `TRAIL_LEN`, напр. на `(20, 45)` |
| спокійніші символи | зменшити `FLICKER_RATIO` до `0.03` |
| фіксований розмір полотна | замінити `FIXED_SIZE = None` на `FIXED_SIZE = (120, 40)` |

`SPAWN_CHANCE` і `DROP_SPEED` пов'язані: чим повільніші краплі, тим довше вони живуть на екрані, тому для тієї ж густоти потрібен менший шанс появи. Якщо розганяєте дощ — підіймайте і `SPAWN_CHANCE`, інакше екран здаватиметься напівпорожнім.

Швидкість руху і плавність картинки — різні речі. `FPS` відповідає за плавність, `DROP_SPEED` — за темп падіння. Щоб дощ став повільнішим, але не смикався, зменшуйте `DROP_SPEED`, а `FPS` не торкайтеся.

## Якщо щось виглядає не так

**Замість символів — порожні прямокутники (`□`) або знаки питання.**
У шрифті терміналу немає японських глифів. Поставте шрифт із підтримкою CJK: Menlo, Cascadia Code, JetBrains Mono або Noto Sans Mono CJK.

**Замість кольорів — незрозумілі послідовності виду `[38;5;48m`.**
Термінал не обробляє ANSI-коди. У Windows запустіть скрипт у Windows Terminal або сучасному PowerShell замість старого `cmd.exe`.

**Усі символи одного кольору, градієнта немає.**
Термінал не підтримує 256 кольорів. Перевірте, що змінна оточення `TERM` має значення `xterm-256color`.

**Картинка "рветься" або символи зсуваються по горизонталі.**
Ознака того, що термінал використовує пропорційний (не моноширинний) шрифт. Виберіть моноширинний.

**Дощ надто рідкий, екран здається напівпорожнім.**
Одразу після запуску так і має бути: екран заповнюється поступово, а на повільній швидкості це займає близько 15 секунд. Якщо й далі рідко — збільште `SPAWN_CHANCE` до `0.004`.

**Скрипт помітно вантажить процесор.**
Зменште `FPS` до `20` — на око різниця майже не помітна.
