Переконайтеся, що у вас встановлено Python 3.

Збережіть код скрипта у файл з розширенням .py, наприклад, matrix.py.

Відкрийте термінал (або командний рядок) у папці зі збереженим файлом.

Виконайте команду:

python matrix.py
(або python3 matrix.py залежно від налаштувань вашої операційної системи).

Щоб зупинити ефект і повернутися до звичайного терміналу, натисніть комбінацію клавіш Ctrl + C.
