# Довідка

## Запуск

1. Переконайтеся, що у вас встановлено Python 3 — сторонні бібліотеки не потрібні.

2. Відкрийте термінал (або командний рядок) у папці з файлом `Matrix.py`.

3. Виконайте команду:

   ```bash
   python3 Matrix.py
   ```

   (або `python Matrix.py` — залежно від налаштувань вашої операційної системи).

   Ім'я файлу пишеться з великої літери **M**: на Linux регістр має значення, і `python3 matrix.py` там не запуститься.

4. Щоб зупинити ефект і повернутися до звичайного терміналу, натисніть **Ctrl + C**.

   Анімація виконується в альтернативному буфері екрана, тому після виходу ваша історія команд лишається на місці — прибирати за скриптом не потрібно.

## Розтягніть вікно перед запуском

Дощ малюється на все вікно терміналу, тому чим воно більше, тим ефектніше виглядає. Повноекранний режим (`Cmd + Ctrl + F` на macOS, `F11` на Windows і Linux) дає найкращу картинку.

Розмір вікна можна змінювати і під час роботи — скрипт підхопить його на льоту.

## Як змінити швидкість, густоту й вигляд

Налаштування зібрані на початку `Matrix.py`, у блоці `--- НАЛАШТУВАННЯ ЕФЕКТУ ---`. Відкрийте файл у будь-якому редакторі й змініть потрібне значення.

Типово дощ опускається неспішно — від 1.5 до 5 рядків на секунду залежно від струмка.

| Хочу... | Що змінити |
|---|---|
| ще повільніший дощ | зменшити `FALL_SPEED`, напр. на `(0.8, 2.5)` |
| швидший дощ | збільшити `FALL_SPEED`, напр. на `(4, 12)` |
| справжню "зливу", як у фільмі | `FALL_SPEED = (12, 30)` і `DROPS_PER_SEC = 0.5` |
| плавнішу картинку | збільшити `FPS` до `120` (темп дощу не зміниться) |
| менше навантаження на процесор | зменшити `FPS` до `30` |
| щільніший потік | збільшити `DROPS_PER_SEC` до `0.15` |
| рідший потік | зменшити `DROPS_PER_SEC` до `0.03` |
| довші хвости | збільшити `TRAIL_LEN`, напр. на `(20, 45)` |
| спокійніші символи | зменшити `FLICKER_PER_SEC` до `0.5` |
| інший колір дощу | змінити `TRAIL_RGB`, напр. на `(70, 140, 255)` для синього |
| фіксований розмір полотна | замінити `FIXED_SIZE = None` на `FIXED_SIZE = (120, 40)` |

Усі значення задані в одиницях часу — за секунду, а не за кадр. Тому `FPS` можна міняти вільно: він впливає лише на плавність картинки, а темп анімації лишається тим самим.

`DROPS_PER_SEC` і `FALL_SPEED` пов'язані: чим повільніші краплі, тим довше вони живуть на екрані, тому для тієї ж густоти потрібно менше нових. Якщо розганяєте дощ — підіймайте і `DROPS_PER_SEC`, інакше екран здаватиметься напівпорожнім.

## Якщо щось виглядає не так

**Замість символів — порожні прямокутники (`□`) або знаки питання.**
У шрифті терміналу немає японських глифів. Поставте шрифт із підтримкою CJK: Menlo, Cascadia Code, JetBrains Mono або Noto Sans Mono CJK.

**Замість кольорів — незрозумілі послідовності виду `[38;5;48m`.**
Термінал не обробляє ANSI-коди. У Windows запустіть скрипт у Windows Terminal або сучасному PowerShell замість старого `cmd.exe`.

**Градієнт хвоста ступінчатий, переходи між відтінками помітні.**
Скрипт не побачив підтримки truecolor і перейшов на запасну палітру з 256 кольорів. Перевірте змінну оточення `COLORTERM` — вона має бути `truecolor` або `24bit`:

```bash
echo $COLORTERM
COLORTERM=truecolor python3 Matrix.py
```

**Усі символи одного кольору, градієнта немає взагалі.**
Термінал не підтримує навіть 256 кольорів. Перевірте, що змінна оточення `TERM` має значення `xterm-256color`.

**Рух схожий на стрибки по цілих символах.**
Так виглядає картинка, коли підсвітка переходу між клітинками не працює через брак кольорів — див. два попередні пункти. Плавність руху тут досягається саме напівтонами.

**Картинка "рветься", смикається або блимає — особливо в перші секунди.**
Термінал не встигає відмальовувати кадри. Найпряміший спосіб — зменшити `FPS` до `30`: даних стає вдвічі менше, а рух лишається плавним, бо плавність тут дають напівтони, а не частота кадрів. Це насамперед стосується великих вікон: на 400×100 потік у чотири рази більший, ніж на 100×40. Terminal.app і вбудована консоль PyCharm помітно повільніші за iTerm2, Alacritty чи WezTerm.

Ще один варіант — зменшити `SHADES` з `32` до `16`: відтінків стане вдвічі менше, тому й оновлень екрана буде менше.

**Символи зсуваються по горизонталі.**
Ознака того, що термінал використовує пропорційний (не моноширинний) шрифт. Виберіть моноширинний.

**Дощ надто рідкий, екран здається напівпорожнім.**
Одразу після запуску так і має бути: екран заповнюється поступово, а на повільній швидкості це займає 15–30 секунд, тим довше, чим вище вікно. Якщо й далі рідко — збільште `DROPS_PER_SEC` до `0.15`.

**Скрипт помітно вантажить процесор.**
Зменште `FPS` до `20` — на око різниця майже не помітна.
