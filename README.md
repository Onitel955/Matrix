# Ефект "Матриці" у терміналі (Matrix Terminal Effect)

Простий Python-скрипт, який створює ефект "цифрового дощу" (падаючого зеленого коду) з культового фільму "Матриця" безпосередньо у вашому терміналі. 

Скрипт використовує стандартні модулі Python і не потребує встановлення сторонніх бібліотек.

## ✨ Особливості

* **Автентичний вигляд:** Використовує суміш латинських літер, цифр та японської катакани (як в оригінальному фільмі).
* **Кольорові переходи (Згасання):** Імітація ефекту світіння — від яскраво-білого на початку "краплі" до яскраво-зеленого та темно-зеленого на її кінці.
* **Адаптивність:** Скрипт автоматично підлаштовується під розміри вашого вікна терміналу за допомогою модуля `shutil`.
* **Жодних залежностей:** Працює "з коробки" (використовує тільки вбудовані модулі `random`, `os`, `time`, `shutil`).
* **Безпечне закриття:** Коректне очищення екрана та повернення курсору після зупинки скрипта через `Ctrl+C`.

## 🚀 Як запустити

1. Переконайтеся, що у вас встановлено **Python 3**.
2. Збережіть код скрипта у файл з розширенням `.py`, наприклад, `matrix.py`.
3. Відкрийте термінал (або командний рядок) у папці зі збереженим файлом.
4. Виконайте команду:

   ```bash
   python matrix.py
   ```
   *(або `python3 matrix.py` залежно від налаштувань вашої операційної системи).*

5. Щоб зупинити ефект і повернутися до звичайного терміналу, натисніть комбінацію клавіш **`Ctrl + C`**.

## ⚠️ Примітка для користувачів Windows

Скрипт використовує ANSI-ескейп коди для розфарбовування тексту та управління курсором. 
* У старих версіях стандартної командної строки (`cmd.exe`) вони можуть відображатися як незрозумілі символи. 
* Наполегливо рекомендується запускати цей скрипт у **Windows Terminal**, сучасному **PowerShell** або у вбудованому терміналі вашого редактора коду (наприклад, VS Code).
